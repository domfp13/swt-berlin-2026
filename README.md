# SWT Berlin 2026 — Cortex Code Demo

Demo repository for the **Cortex Code** walkthrough at SWT Berlin.

## What is this?

Cortex Code (CoCo) is Snowflake's agentic IDE for data and software engineering. This repo hosts the demo assets used to show the audience how to work with Snowflake using Cortex Code.

## What we'll cover

- Connecting Cortex Code to a Snowflake account
- Exploring data with natural language
- Writing and running SQL/Python against Snowflake
- Using skills to automate common workflows (e.g. semantic views, dashboards, apps)
- Building and iterating on a small app or notebook live

## Getting started

1. Open this folder in Cortex Code.
2. Connect to your Snowflake account.
3. Follow along with the presenter's prompts.
